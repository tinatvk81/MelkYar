# ملک‌یار (MelkYar) — سامانه مدیریت فایل‌های املاک

بک‌اند فاز ۱ (MVP) با Django + Django REST Framework، طبق نقشه‌راهی که قبلاً
باهم طراحی کردیم. این نسخه شامل: کاربران با نقش مدیر/مشاور، مدل کامل فایل
ملکی (فروش/پیش‌خرید/اجاره/رهن‌کامل)، کنترل دسترسی ردیفی، ماژول قراردادهای
رو‌به‌اتمام، و اسکلت Import اکسل.

## ⚠️ نکته‌ی مهم درباره‌ی این تحویل

این کد در محیطی نوشته شده که به اینترنت دسترسی ندارد، پس امکان نصب واقعی
Django/اجرا/تست در همینجا نبود. کدها را از نظر نحوی (syntax) با
`python -m py_compile` روی همه‌ی فایل‌ها چک کردم و مشکلی نداشتند، ولی شما
باید مراحل زیر را روی سیستم خودتان (که اینترنت دارد) اجرا کنید تا واقعاً
تست و اجرا شود.

## راه‌اندازی

```bash
# 1) ساخت محیط مجازی
python -m venv venv
source venv/bin/activate      # ویندوز: venv\Scripts\activate

# 2) نصب پکیج‌ها
pip install -r requirements.txt

# 3) ساخت فایل .env از روی نمونه، و ساخت SECRET_KEY
cp .env.example .env
python -c "import secrets; print(secrets.token_urlsafe(50))"
# مقدار چاپ‌شده را داخل .env جلوی SECRET_KEY= بگذارید
# برای توسعه‌ی محلی همان مقادیر پیش‌فرض .env کافی است (DEBUG=True را هم ست کنید)

# 4) ساخت جداول دیتابیس
python manage.py makemigrations
python manage.py migrate

# 5) ساخت اکانت مدیر اول (superuser)
python manage.py createsuperuser

# 6) اجرا
python manage.py runserver
```

فایل `SECURITY.md` را هم قبل از هر استفاده‌ی واقعی (نه فقط تست محلی) حتماً بخوانید — چک‌لیست کامل امنیتی قبل از رفتن روی سرور واقعی آنجاست.

بعد از اجرا:
- پنل ادمین جنگو (برای شروع سریع، قبل از آماده شدن پنل اختصاصی): `http://127.0.0.1:8000/admin/`
- ورود API (JWT): `POST /api/auth/login/` با `{"username": "...", "password": "..."}`
- فهرست/ثبت فایل ملکی: `GET/POST /api/properties/listings/`
- قراردادهای رو‌به‌اتمام: `GET /api/properties/renewals/`
- ثبت نتیجه‌ی تماس تمدید: `POST /api/properties/renewals/{id}/log-contact/`
- مدیریت مشاوران (فقط مدیر): `GET/POST /api/accounts/agents/`

## ساختار پروژه

```
melkyar/
  melkyar/          تنظیمات اصلی پروژه (settings, urls)
  accounts/         کاربران، نقش‌ها، لاگ فعالیت، مدیریت مشاوران
  properties/       مدل فایل ملکی + ۴ زیرمدل معامله + جستجو + یادآوری تمدید
```
